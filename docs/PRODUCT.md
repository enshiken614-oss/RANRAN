# HER UNIVERSE 产品与实施规划

核心命题：**在无数个平行宇宙里，我依然会选择遇见你。**

以“为她准备的一颗星”为入口，把导航变成可探索的私人星系。情绪来自内容、节奏与反馈，技术负责支撑。真实资料未提供，一切示例明确标注，不编造共同经历。

## 信息架构与体验路径

| 空间       | 用户要完成的事情                           | 反馈                             |
| ---------- | ------------------------------------------ | -------------------------------- |
| 宇宙入口   | 进入或跳过开场，自主选择声音               | 星光渐显、欢迎语、镜头推进       |
| 主星系     | 探索六个空间                               | 轨道、聚焦、访问进度与返回       |
| 记忆博物馆 | 按主题与时间浏览、翻拍立得、查看故事和收藏 | 详情、切换与缺图替代             |
| 时间星球   | 看相爱时长、生日与纪念日                   | 实时读数、下一次日期与待填写状态 |
| 游戏星球   | 默契测试、寻找星星、命运选择               | 开始、进展、结算、重新开始       |
| 情书星球   | 打开信封、阅读、写未来草稿                 | 阅读仪式、日期状态、本机保存提示 |
| 梦境星球   | 添加和完成愿望、保存胶囊                   | 成长意象与已完成纪念             |
| 秘密宇宙   | 探索配置条件对应的奖励                     | 解锁与最终告白星图               |

主路径为开场 → 主星系 → 星球内容 → 返回。首次访问保留仪式，再访优先继续。星球与常规导航并存，使触摸、键盘和辅助技术都能到达内容。

## 视觉规则

- 宇宙黑和深夜蓝建立空间，月光银承担文字，香槟金标记焦点，紫色只作环境色。
- 清晰中文正文搭配克制英文标记；标题、正文、说明形成明确层级。
- 留白与不同尺度天体制造景深，轨道引导视线，避免密集装饰。
- 记忆用温暖纸张，时间用精确数字，游戏用星图，情书用信封，愿望用成长隐喻。
- 动画用于进入、选择、完成和返回，尊重 `prefers-reduced-motion`；低性能设备减少粒子与持续运动。
- 移动端优先：触控目标足够大、弹层可滚动、横竖屏可读，背景不阻挡操作。

## 技术架构

采用 Next.js App Router、React、TypeScript、Lucide 和自定义 CSS。用轻量 Canvas / SVG 与 CSS 营造宇宙，不为装饰引入大型 3D 引擎。

内容在 `src/config/ourStory.ts`，纯逻辑在 `src/lib/`，各空间为独立组件。服务器验证访问和私有媒体权限，个人配置通过受保护数据路径提供，避免在公开前端包中包含私密文字。公开插画位于 `public/art/`，真实素材使用私有媒体目录或后续私有对象存储。

本地交互使用浏览器存储并处理失败，不承诺同步。未来共同编辑需数据库、独立身份认证、权限、服务端时间与迁移/导出方案。

## 分阶段任务与完成标准

1. **规划：** 明确信息架构、类型、视觉规则与隐私边界。
2. **初始化：** 框架、配置、依赖锁文件与脚本。
3. **核心流程：** 入口、星系、导航、记忆与时间完整可达。
4. **高级互动：** 三款游戏可完成和重开，情书可读，愿望可保存，彩蛋可累积。
5. **视觉精修：** 移动端、键盘、降级、缺图反馈和转场。
6. **验收：** 实际执行类型检查、逻辑测试、构建与浏览器流程，修复发现的问题。
7. **交付：** 中文维护与部署说明；真实资料和正式发布由拥有者决定。

## 验收项目

以下定义检查内容，不预先宣称通过：

- 构建、类型与测试实际运行，并有结果记录。
- 桌面和手机无空白页、明显溢出或阻挡操作的动画。
- 六个空间可以到达和返回，焦点与键盘操作合理。
- 图片缺失有替代，详情、切换和视频可用。
- 日期覆盖配置时区、跨年、闰日与空值。
- 三款游戏有开始、过程、结果、重新开始。
- 收藏、草稿、愿望、探索进度按设计保存；存储不可用有反馈。
- 首访与再访不同，声音仅在用户操作后开始，减少动态效果生效。
- 生产缺少凭据时关闭，错误口令拒绝，Cookie 和媒体授权有效。
- 未认证请求不能读取私人配置或媒体，公开构建资源不含私人文字。
- 不默认发布，不把客户端日期锁或本机保存描述为安全同步。

## 后续演进

优先增加真实内容。按需求逐步加入双人账户、私有媒体存储、共同愿望数据库、真正服务端时间锁与内容编辑界面。保留版本化数据、迁移和导出能力，避免回忆只存在于单个浏览器。
