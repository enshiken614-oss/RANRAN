## 复验方法

常规检查：

```bash
npm ci
npm run typecheck
npm test
npm run build
npm run test:e2e -- universe
```

若没有系统 Chromium，先运行 `npx playwright install chromium`。环境也支持通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 选择已有浏览器。

生产隐私测试需独立启动生产服务器，并通过本机环境变量提供临时测试凭据。将 `PLAYWRIGHT_AUTH_REQUIRED` 设置为 `1`，`PLAYWRIGHT_BASE_URL` 指向该服务器，`PLAYWRIGHT_TEST_ACCESS_CODE` 设置为该测试服务器的口令，再运行 `npm run test:e2e -- privacy`。未设置这些变量时，这两项测试明确跳过，不能视为通过。

媒体集成脚本为 `tests/media-integration.ts`。设置测试服务器的 `QA_BASE_URL` 和 `QA_ACCESS_CODE` 后运行 `node --import tsx tests/media-integration.ts`；脚本创建临时合成素材并在结束时清理。不要对存放真实资料的公开生产实例执行素材写入测试。

## 已知边界与交付状态

网站使用原创 SVG 与一次绘制的轻量 Canvas 星空，没有大型 WebGL 场景；页面首次加载 JavaScript 约 129 kB（构建报告）。私有媒体保持会话验证，图片按需加载。

收藏、愿望、草稿和探索进度为本机保存。日期信件与胶囊使用设备时间，仅提供阅读仪式。跨设备共同编辑、云端上传与真正保密的定时发布需要后续数据库、独立账户、私有存储和服务端时间校验。
